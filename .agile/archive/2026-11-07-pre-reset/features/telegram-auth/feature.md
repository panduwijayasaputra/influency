# Feature: Telegram Login & Sessions

**Slug:** telegram-auth
**Handoff phase:** Phase 2 — Telegram Login and public creator route

## Overview

Users and creators sign in with Telegram Login (OIDC). Influency creates its own secure session and manages roles internally. Login is never required to browse public creator pages.

## Stories

- US-006: Log In with Telegram (high)
- US-007: Secure Session & Logout (high)
- US-008: Return to Original Page After Login (high)
- US-009: Current User & Role-Based Access (high)
