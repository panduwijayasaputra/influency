# US-023: Koin Package Catalog

**Status:** backlog
**Priority:** high
**Feature:** koin-wallet

## Description

As an admin, I want to manage the Koin packages users can buy, so that pricing can change without code changes.

## Acceptance Criteria

- [ ] Admins can create, edit and deactivate packages with a Koin amount and IDR price (whole numbers)
- [ ] Seeded packages are clearly labeled as example values (e.g. 25 Koin / Rp25.000) — not final pricing
- [ ] Users see only active packages on the wallet page, with IDR price, Koin amount and refund/validity policy text (placeholder until decided)
- [ ] Editing a package does not change orders that were already created
