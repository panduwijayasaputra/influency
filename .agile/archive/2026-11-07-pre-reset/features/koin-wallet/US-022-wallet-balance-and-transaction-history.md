# US-022: Wallet Balance & Transaction History

**Status:** backlog
**Priority:** high
**Feature:** koin-wallet

## Description

As a logged-in user, I want to see my Koin balance and every Koin movement, so that I know exactly what I bought and spent.

## Acceptance Criteria

- [ ] A new user has a wallet with 0 Koin
- [ ] `/wallet` shows the current balance and a paginated history of credits and debits with type, amount, date (Asia/Jakarta) and related item
- [ ] History entries can never be edited or deleted; corrections appear as new entries
- [ ] A user can only see their own wallet
