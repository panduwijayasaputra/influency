# US-018: Set Premium Post Price & Duration

**Status:** ready_for_uat
**Priority:** high
**Feature:** creator-content

## Description

As an approved creator, I want to set a Koin price and access period for a premium post, so that I decide what my content is worth (e.g. 5 Koin for 7 days).

## Acceptance Criteria

- [ ] A creator can set a price in whole Koin and an access duration for a premium post, within configured system limits
- [ ] Price must be greater than zero and duration must be positive
- [ ] Changing the price or duration creates a new offer version that applies to future purchases only
- [ ] Existing buyers keep the terms they purchased under
