# Feature: Content Access & Protected Media

**Slug:** content-access
**Handoff phase:** Phase 3 — Content, media and entitlement

## Overview

The server decides who may view premium content and hands out short-lived media access only after that decision. Implements the entitlement rule in handoff §6.4.

## Stories

- US-020: Server-Side Access Check (high)
- US-021: Short-Lived Media Access for Entitled Viewers (high)
- US-050: Access via Purchases, Subscriptions & Archive Grants (high) — monetization phase
