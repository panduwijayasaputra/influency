# US-043: Audit Log of Sensitive Actions

**Status:** backlog
**Priority:** medium
**Feature:** admin-operations

## Description

As an admin, I want every sensitive admin action to be logged, so that we can see who did what and when.

## Acceptance Criteria

- [ ] Creator approvals, package changes, refunds, payout actions and moderation actions are written to an audit log with actor, action, resource and time
- [ ] Audit entries cannot be edited or deleted from the application
- [ ] Admins can search the audit log by actor, action and resource
