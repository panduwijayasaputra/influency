# US-063: Following Page

**Status:** backlog
**Priority:** medium
**Feature:** mobile-first-ui

## Description

As a signed-in user, I want a list of creators I follow, so that I can revisit them quickly.

## Acceptance Criteria

- [ ] **Diikuti** (`/following`) lists followed creators as cards: cover, avatar, name, @username and bio. Tapping a card opens the creator profile.
- [ ] Sort options are Baru diikuti / Nama A–Z, with a Grid / Vertikal display toggle.
- [ ] The empty state "Kamu belum mengikuti siapa pun" links to Jelajahi.
- [ ] Following is shown as free and separate from Langganan. Data is dummy until a follow backend exists. `following` is a reserved slug.
