# US-073: New / Edit Post Form

**Status:** backlog
**Priority:** medium
**Feature:** mobile-first-ui

## Description

As a creator, I want a mobile-friendly form to create or edit a post, so that I can publish free or premium content from my phone.

## Acceptance Criteria

- [ ] Post Baru and Edit post (from the profile or the post ··· menu) open the existing studio post pages, restyled to the design. The mobile layout has a back header and a sticky save action.
- [ ] **Media** holds up to **5** photos/videos mixed in one post. Items can be reordered by dragging, and the first item is the cover. Tapping an item previews it full screen. "Tambahkan minimal satu foto atau video" appears when the media list is empty. The existing upload and limit rules (US-016, US-017, US-049) still apply.
- [ ] Caption field.
- [ ] **Akses** is set with Gratis / Premium. Gratis shows "Semua orang bisa melihat post ini. Post gratis tidak menampilkan Kirim Tip." Premium requires a price of 5–1.000 Koin, using the existing offer API.
- [ ] Existing draft, publish and archive behaviour and tests keep working. Validation errors show inline in Bahasa Indonesia.
