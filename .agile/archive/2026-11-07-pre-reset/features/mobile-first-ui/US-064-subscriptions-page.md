# US-064: Subscriptions Page

**Status:** backlog
**Priority:** medium
**Feature:** mobile-first-ui

## Description

As a signed-in user, I want a simple list of creators I subscribe to, so that I know whose premium content I can access and until when.

## Acceptance Criteria

- [ ] **Langganan** (`/subscriptions`) lists subscribed creators with avatar, name, @username and status: Aktif with "x hari lagi", or Berakhir. Tapping a row opens the creator profile.
- [ ] There is **no** sort and **no** display toggle.
- [ ] The empty state "Belum ada langganan aktif" explains that subscriptions are separate from following and are started from a creator's profile.
- [ ] A note says that renewal is manual and that card details and renewal controls are "Perlu konfirmasi". Data is dummy until US-029.
