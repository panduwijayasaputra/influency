# US-026: Creator Subscription Plans

**Status:** backlog
**Priority:** high
**Feature:** content-purchases

## Description

As an approved creator, I want to offer a subscription plan for all my premium content, so that fans can pay once for everything I post (e.g. 30 Koin for 30 days).

## Acceptance Criteria

- [ ] A creator can create and edit a plan with a name, whole-Koin price and duration within system limits
- [ ] Changing a plan creates a new version that applies to future purchases only
- [ ] The active plan is shown on the creator's public page
- [ ] A creator can only manage their own plans
