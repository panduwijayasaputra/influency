# US-040: Payments & Reconciliation Report

**Status:** backlog
**Priority:** medium
**Feature:** admin-operations

## Description

As an admin, I want to compare gateway payments with credited Koin, so that I can spot mismatches quickly.

## Acceptance Criteria

- [ ] Admins can list top-up orders filtered by status and date, with gateway transaction details
- [ ] A report compares paid totals, credited Koin and ledger totals for a period and highlights mismatches
- [ ] Quarantined/flagged payments are listed for review
- [ ] Only admins can access these views
