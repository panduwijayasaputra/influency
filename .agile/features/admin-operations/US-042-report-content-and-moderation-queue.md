# US-042: Report Content & Moderation Queue

**Status:** backlog
**Priority:** medium
**Feature:** admin-operations

## Description

As a logged-in user, I want to report a post that breaks the rules, so that Influency can review and remove harmful content.

## Acceptance Criteria

- [ ] A logged-in user can report a post with a reason
- [ ] Admins see reported posts in a moderation queue and can dismiss, hide or remove them
- [ ] Admins can suspend a creator or user
- [ ] Moderation actions never change financial history
