# Feature: Creator Onboarding

**Slug:** creator-onboarding
**Handoff phase:** Phase 2 — Telegram Login and public creator route

## Overview

A logged-in user applies to become a creator and reserves a unique slug; an admin approves or rejects. Approved creators get Studio access and keep their subscriber abilities. KYC/payout details are deferred.

## Stories

- US-010: Apply to Become a Creator (high)
- US-011: Admin Reviews Creator Applications (high)
- US-012: Creator Edits Profile (medium)
