# US-019: Publish a Post

**Status:** backlog
**Priority:** high
**Feature:** creator-content

## Description

As an approved creator, I want to publish a post, so that it appears on my public page.

## Acceptance Criteria

- [ ] Publishing moves a post to `PUBLISHED` (or `PENDING_REVIEW` if moderation is required by configuration)
- [ ] A premium post cannot be published without an active offer
- [ ] Published posts appear on the creator page in the right section (free or premium preview)
- [ ] A creator can hide a published post, which removes it from the public page
