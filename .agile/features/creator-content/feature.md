# Feature: Creator Content Studio

**Slug:** creator-content
**Handoff phase:** Phase 3 — Content, media and entitlement

## Overview

Approved creators create posts, upload images and video to private storage, choose free or premium, set per-post Koin price and duration, and publish.

## Stories

- US-015: Create and Edit Draft Posts (high)
- US-016: Upload Images to Private Storage (high)
- US-017: Upload Video to Posts (medium)
- US-018: Set Premium Post Price & Duration (high)
- US-019: Publish a Post (high)
