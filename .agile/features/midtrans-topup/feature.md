# Feature: Midtrans Sandbox Top-Up

**Slug:** midtrans-topup
**Handoff phase:** Phase 5 — Midtrans Sandbox integration

## Overview

Users buy Koin packages through Midtrans Snap in Sandbox mode. Only a verified server-to-server notification (or reconciliation) credits the wallet, exactly once. No real money and no production keys.

## Stories

- US-031: Top Up Koin via Midtrans Snap Sandbox (high)
- US-032: Credit Koin from Verified Payment Notification (high)
- US-033: Top-Up Status Page (medium)
- US-034: Reconcile Pending Top-Ups (high)
