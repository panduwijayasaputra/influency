# US-038: Request a Payout

**Status:** backlog
**Priority:** medium
**Feature:** creator-earnings

## Description

As an approved creator, I want to request a payout of my available earnings, so that I can get paid for my content.

## Acceptance Criteria

- [ ] A creator can request a payout up to their available balance
- [ ] The same available balance cannot be requested twice while a request is open
- [ ] The request appears in payout history with status `REQUESTED`
- [ ] Minimum amount and fees come from configuration labeled as example values
